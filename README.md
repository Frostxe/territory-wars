## 🎮 Особенности игры

- 🔗 **Игра по ссылке в 1 клик**: Создайте комнату, нажмите «Скопировать ссылку» и отправьте друзьям в Telegram, Discord или WhatsApp. Никакой регистрации!
- 👥 **От 2 до 6 игроков**: Сражайтесь с друзьями или добавьте **умных ботов (AI)**, если хотите потренироваться в одиночку.
- 🎲 **Простая и затягивающая механика**:
  1. Выберите свою территорию, где больше 1 армии.
  2. Кликните по соседней территории врага или нейтрала.
  3. Бросок кубиков определяет победителя битвы!
  4. В конце хода получайте подкрепления за размер подконтрольной империи.
- 🔊 **Встроенные звуковые эффекты**: Синтезатор звуков на Web Audio API (не требует внешних файлов и не лагает).
- 💬 **Внутриигровой чат и быстрые реакции**: Отправляйте эмодзи (🔥, ⚔️, 😂, 👑, 🛡️, 💀), которые взлетают по экрану.
- 📱 **Адаптивный интерфейс**: Одинаково удобно играть как с компьютера (мышкой), так и с любого смартфона (тачскрин).

## 🚀 Быстрый запуск на компьютере

### Требования:
- Установленный [Node.js](https://nodejs.org/) (версия 18 или новее)

### Установка и запуск:

```bash
# Перейдите в папку с игрой
cd territory-wars

# Установите зависимости
npm install

# Запустите сервер
npm start
```

После этого откройте в браузере:
👉 **`http://localhost:3000`**

Чтобы протестировать мультиплеер на одном компьютере, откройте эту же ссылку во второй вкладке (или в режиме инкогнито) и войдите в ту же комнату по коду или ссылке.

## 🌐 Как бесплатно запустить онлайн (чтобы играть с друзьями по интернету)

Вы можете выложить игру в интернет абсолютно бесплатно за 2 минуты:

### Вариант 1: Бесплатный хостинг Render.com (Рекомендуется)
1. Зарегистрируйтесь на [Render.com](https://render.com/) через ваш GitHub аккаунт.
2. Нажмите **New +** ➡️ **Web Service**.
3. Выберите ваш репозиторий с игрой на GitHub.
4. Укажите параметры:
   - **Environment**: `Node`
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
5. Нажмите **Deploy Web Service**.
6. Через 1 минуту Render выдаст вам постоянную публичную ссылку (например `https://territory-wars.onrender.com`), которую можно отправлять друзьям!

### Вариант 2: Мгновенно через LocalTunnel (для быстрого теста)
```bash
npx localtunnel --port 3000
```
Вы получите публичную ссылку прямо на ваш локально запущенный сервер!

## 🛠️ Стек технологий
- **Бэкенд**: Node.js, Express, Socket.IO
- **Фронтенд**: HTML5, Vanilla CSS3 (Neon Glassmorphism), Vanilla JavaScript, SVG динамическая карта, Web Audio API
- **Архитектура**: Server-Authoritative State Sync (сервер валидирует все броски кубиков и захваты, исключая читерство)

Разработано для быстрых и веселых баталий с друзьями! 👑
